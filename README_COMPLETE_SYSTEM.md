# 🎵 智能卡拉OK搜尋系統 - 完整使用指南

## 🌟 系統特色

✨ **無需本地伺服器** - 前端完全獨立運作  
🤖 **自動化爬蟲** - 一鍵更新資料庫並推送GitHub  
🧠 **智能搜尋** - 多資料源整合，模糊匹配  
📱 **響應式設計** - 支援電腦、平板、手機  
🔄 **自動部署** - 推送後自動更新線上版本

## 🚀 快速開始

### **方法1: 使用線上版本 (最簡單)**
```
直接開啟: https://karaoke-search-theta.vercel.app/
```

### **方法2: 本地獨立版本 (無需伺服器)**
```bash

open standalone_frontend.html

python3 auto_update_and_deploy.py
```

## ⚠️ 注意事項

### **使用限制**
- 🕷️ **爬蟲頻率**: 建議每週或每月執行一次
- 📊 **資料來源**: 基於台灣點歌王公開資料
- 🌐 **網路需求**: 爬蟲需要穩定網路連線
- 💾 **儲存空間**: 完整資料庫約 10-50MB

### **最佳實踐**
- 優先使用線上版本獲得最新資料
- 本地版本適合離線使用或客製化
- 爬蟲執行建議在非尖峰時段
- 定期備份重要資料檔案

## 🆘 問題排解

### **常見問題**

**Q: 搜尋沒有結果？**
A: 嘗試簡化關鍵字，或使用模糊搜尋

**Q: 爬蟲執行失敗？**  
A: 檢查網路連線，稍後重試，支援斷點續傳

**Q: 無法推送到GitHub？**
A: 檢查Git配置和網路連線，確認有推送權限

**Q: 線上版本沒有更新？**
A: 等待5-10分鐘讓Vercel完成部署
